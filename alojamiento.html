Alojamiento web

El alojamiento web, tambien llamado hosting, es un servicio que guarda los archivos de una pagina en un servidor conectado a internet.

Gracias al alojamiento, otras personas pueden visitar una pagina mediante un enlace. Tambien se puede utilizar un dominio para tener una direccion personalizada.

Pasos para publicar una pagina

  1. Guardar los archivos HTML en una carpeta.
  2. Elegir un servicio de alojamiento web.
  3. Subir los archivos al servidor.
  4. Abrir el enlace y comprobar que funcione.

Antes de publicar, se deben revisar los hipervinculos y comprobar que todos los archivos esten incluidos.
