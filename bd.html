CREAR UNA BASE DE DATOS

¿Que es una base de datos?

Una base de datos es un conjunto organizado de informacion. En MySQL se crea utilizando CREATE DATABASE.

Ejemplo de sintaxis

CREATE DATABASE escuela;
USE escuela;

CREATE DATABASE crea la base de datos llamada escuela. USE permite seleccionarla para trabajar en ella.

Importancia

Las bases de datos permiten guardar y consultar informacion de forma organizada.
