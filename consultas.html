Consultas en MySQL

Las consultas permiten buscar y mostrar informacion que se encuentra guardada en una base de datos.

Mostrar todos los registros

SELECT * FROM alumnos;

Mostrar algunas columnas

SELECT nombre, grupo
FROM alumnos;

Buscar por condicion

SELECT * FROM alumnos
WHERE grupo = '4A';

Modificar un registro

UPDATE alumnos
SET grupo = '4B'
WHERE nombre = 'Ana';

WHERE permite indicar que registros se quieren consultar o modificar. Es importante utilizarlo correctamente al actualizar datos.
