CONSULTAS EN MYSQL

¿Que son las consultas?

Las consultas permiten buscar y mostrar informacion que se encuentra guardada en una base de datos.

Mostrar todos los registros

SELECT * FROM alumnos;

Mostrar algunas columnas

SELECT nombre, grupo
FROM alumnos;

Buscar por condicion

SELECT * FROM alumnos
WHERE grupo = '4A';

Modificar un registro

UPDATE alumnos
SET grupo = '4B'
WHERE nombre = 'Ana';

SELECT permite consultar informacion y WHERE permite indicar una condicion. UPDATE modifica los datos seleccionados.
