Crear paginas web

Para crear una pagina web se utiliza un editor de codigo donde se escribe HTML. El archivo se guarda con la extension .html y despues se abre en un navegador.

Etiquetas principales

  • h1: crea un titulo principal.
  • p: agrega un parrafo.
  • ul: crea una lista.
  • li: agrega un elemento a la lista.
  • a: crea un hipervinculo.

Ejemplo

<h1>Mi pagina</h1>
<p>Bienvenidos a mi sitio web.</p>
