HTML

¿Que es HTML?

HTML significa HyperText Markup Language. Es un lenguaje de marcado que se utiliza para crear y organizar el contenido de las paginas web.

¿Para que sirve?

Sirve para agregar titulos, textos, imagenes, tablas, enlaces y formularios a una pagina web.

Estructura basica

<!DOCTYPE html>
<html>
<head>
    <title>Mi pagina</title>
</head>
<body>
    <h1>Hola mundo</h1>
    <p>Esta es mi pagina web.</p>
</body>
</html>
