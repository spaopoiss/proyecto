MySQL

MySQL es un sistema que permite crear, organizar y administrar bases de datos. Utiliza SQL para trabajar con la informacion.

Instrucciones principales

  • CREATE DATABASE: crea una base de datos.
  • CREATE TABLE: crea una tabla.
  • INSERT INTO: agrega registros.
  • SELECT: consulta informacion.
  • UPDATE: modifica informacion.
  • DELETE: elimina registros.

Ejemplo

SELECT * FROM alumnos;

Esta consulta muestra todos los registros y columnas de la tabla alumnos.
