INSERTAR REGISTROS EN MYSQL

¿Que es un registro?

Un registro es una fila de datos dentro de una tabla. Para agregarlo se utiliza INSERT INTO.

Ejemplo de sintaxis

INSERT INTO alumnos (nombre, edad, grupo)
VALUES ('Ana', 17, '4A');

Explicacion

En este ejemplo se agrega una alumna con nombre, edad y grupo. Los textos se escriben entre comillas simples.
