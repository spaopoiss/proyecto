CREAR TABLAS EN MYSQL

¿Que son las tablas?

Las tablas permiten almacenar datos en filas y columnas. Cada columna tiene un nombre y un tipo de dato.

Ejemplo de sintaxis

CREATE TABLE alumnos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(50),
    edad INT,
    grupo VARCHAR(10)
);

Tipos de datos

  • INT: numeros enteros.
  • VARCHAR: texto.
  • PRIMARY KEY: identifica cada registro.
  • AUTO_INCREMENT: genera identificadores automaticamente.
